# Личное дело — редактор персонажей

Небольшой статический сайт: заполняете анкету, листаете внешность — справа собирается карточка-досье, которую можно сохранить как PNG.

Сборка не нужна: только `index.html`, `style.css`, `script.js` и папка `assets/`.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите в него все файлы.
2. `Settings → Pages → Build and deployment`: источник `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт появится по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

## Локальный запуск

Если открыть `index.html` двойным кликом, страница работает, но браузер **не даст сохранить PNG** (картинки из файла считаются «чужими»). Запустите маленький сервер:

```
python -m http.server 8000
```

и откройте http://localhost:8000.

## Как заменить болванки на свои картинки

Каждая часть внешности — отдельный PNG с **прозрачным фоном**. Все слои рисуются в одном кадре, поэтому в каждом файле элемент должен стоять на своём месте относительно образца.

- Размер: 224 × 319 px (или любой с теми же пропорциями, например 448 × 638 — так будет чётче).
- Просто замените файл, сохранив имя.

| Папка | Файлы | Количество |
|---|---|---|
| `assets/head/` | `head-1.png` … `head-3.png` | 3 формы головы (с ушами и шеей) |
| `assets/hair/` | `hair-1.png` … `hair-5.png` | 5 причёсок |
| `assets/mustache/` | `mustache-1.png` … `mustache-3.png` | 3 вида усов |
| `assets/beard/` | `beard-1.png` … `beard-3.png` | 3 вида бороды |
| `assets/clothes/` | `clothes-1.png` … `clothes-10.png` | 10 одежд |

Порядок наложения снизу вверх: одежда → голова → борода → усы → причёска.
Серый фон портрета рисуется кодом (`PORTRAIT.bg` в начале `script.js`).

Для причёсок, усов и бороды в листалке есть вариант «нет».

### Если нужно другое количество вариантов

В начале `script.js` в списке `PARTS` поменяйте `count` — и положите в папку нужное число файлов.

### Вернуть болванки

```
pip install pillow
python tools/make_placeholders.py
```

## Что можно настроить

В `script.js`: списки национальностей и религий (`NATIONALITIES`, `RELIGIONS`), цвета карточки (`C`), качество итоговой картинки (`SCALE`).
